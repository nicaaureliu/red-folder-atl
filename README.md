# red-folder-atl

Static site files for the Red Folder ATL project. The `public/` directory contains HTML, images and templates.

Quick start

- Open `public/index.html` in a browser.
- Or serve locally from the repo root:

```powershell
# From the repo root
python -m http.server 8000
# then open: http://localhost:8000/public/
```

Deploy

- Enable GitHub Pages in repository Settings and point it to the `main` branch. If you prefer automatic deployment, add a Pages workflow to deploy the `public/` folder.

Contributing

- Make changes on a branch and open a pull request against `main`.
